# 联锁对抗 BP 助手

一个为《明日方舟》玩家自创玩法“联锁对抗”制作的本地 Python 桌面软件。

第一阶段已经支持：

- 按名称、星级、职业和子职业分支筛选干员
- 带本地干员头像的卡片式 BP 视图与职业图标筛选
- 高分屏自适应窗口、居中比赛创建卡和二级规则设置
- 配置比赛轮数、Ban/Pick 数量、起拍价、加价和封顶价
- 比赛创建前设置不限数量的全局干员 Ban，并可一键全局禁用整个分支
- 主持人按 A/B 顺序完成公开 Ban，确认后导出含全部 Ban 的选手配置
- 选手读取最终配置后按轮导出 Pick
- 导出带比赛编号与完整性校验的 `.bpselect` 选手文件
- 主办方导入双方文件并执行规则检查
- 同轮重复 Pick 自动合并
- 使用可复核随机种子生成分轮拍卖顺序
- 拍卖时只显示当前干员，记录每次出价、放弃、成交或流拍
- 拍卖倒计时可在规则参数中配置，默认 20 秒；超时后自动确认领先方或流拍
- 已完成拍卖按轮次分区展示，并支持选择干员重新拍卖
- 保存和恢复完整 `.bprace` 比赛存档
- 登记实际上场阵容、完美通关状态并自动计算人力资源消耗
- 结算时可分别修正双方最终分数
- 导出带 UTF-8 BOM 的 CSV 赛后汇总，可直接用 Excel 打开

## 启动

源码需要 Python 3.11 或更高版本，不需要安装第三方运行依赖。公开仓库不
包含 EXE、比赛存档或第三方游戏视觉素材。

在 Windows 上双击：

```text
启动联锁对抗助手.bat
```

如果系统对中文文件名的批处理兼容性有问题，也可以双击同目录下的：

```text
start_app.bat
```

启动器会使用无控制台的 `pythonw.exe` 打开软件。若启动异常，会弹出提示并在项目目录生成 `启动错误.log`。

也可以在项目目录运行：

```powershell
python app.py
```

仅启动红蓝双方共用的赛前 BP 工作台：

```powershell
python player_bp_app.py
```

## 推荐操作顺序

1. 主办方在“比赛”页设置规则、双方名称和赛前全局 Ban，并创建比赛。
2. 主持人在“主持人 Ban”页按 A/B 顺序完成双方分支与干员 Ban。
3. 主持人确认 Ban 后，从该页面导出最终 `.bpmatch` 选手配置；文件包含全局 Ban 和双方主持人 Ban。
4. 双方选手读取最终配置，完成第 1 轮 Pick，分别导出 `.bpselect` 文件。
5. 主办方读取最终配置，导入双方第 1 轮文件，生成并完成第 1 轮拍卖。
6. 双方完成第 2 轮 Pick，再分别导出第 2 轮文件；主办方导入并完成第 2 轮拍卖。
7. 在“阵容结算”中双击干员，标记实际上场人员。
8. 勾选双方完美通关状态，计算结果并保存比赛、导出 CSV。

## 当前规则实现

- 默认每场 2 轮，每轮每方选择 5 名干员；每轮上限为 7 名。
- 每方默认 Ban 1 个子职业分支和 4 名干员。
- 4 星及以下、5 星、6 星默认分别以 2、4、8 点起拍。
- 每次默认加价 1 点，价格封顶 24 点。
- 拍卖倒计时默认 20 秒，可在比赛规则参数中调整。
- 同一选手不能跨轮重复 Pick。
- 软件按“选取一轮、拍卖一轮”的顺序执行；上一轮未拍完时不能生成下一轮拍卖池。
- 双方同轮 Pick 同一干员时，拍卖池只保留一次并记录双方共同提名。
- 双方的最终 Ban 合并应用；如 Pick 与任一方有效 Ban 冲突，主办方导入时会阻止开拍。
- 人力消耗 = 上场干员成交价之和 + 未使用干员成交价之和的一半。
- 只有一方完美通关时该方获胜；双方都完美通关时消耗较少者获胜。

## 文件说明

| 扩展名 | 用途 |
| --- | --- |
| `.bpmatch` | 含比赛规则、全局 Ban 和双方主持人 Ban 的最终选手配置 |
| `.bpselect` | 单方保密 Ban/Pick 文件，只发送给主办方 |
| `.bprace` | 包含拍卖、阵容和结算进度的完整比赛存档 |
| `.csv` | 赛后明细与人力资源汇总 |

文件中的校验值可以发现误修改或文件损坏，但它不是密码学身份签名。正式线上赛事如需防止蓄意伪造，应在后续版本加入主办方密钥签名或服务器提交。

## 干员数据

`data/operators.csv` 是软件实际读取的数据表，目前由简中服公开游戏数据生成。要更新名单，可准备新的：

- `character_table.json`
- `uniequip_table.json`

然后运行：

```powershell
python tools/build_operator_csv.py character_table.json uniequip_table.json data/operators.csv
```

生成器会保留八种正式职业、排除游戏数据中标记为不可获得的临时角色，并写入名称、星级、职业和子职业分支。

本项目是非官方玩家工具。《明日方舟》相关名称与数据归其权利人所有。
